# java_maven_template

Project Template for Java using Maven

## How to use this Java Maven Template

1. Rename the JenkinsTemplate to Jenkinsfile
2. Update the image name in the Jenkinsfile
3. Update the artifactId in the pom.xml
4. Change the parent if necessary
5. [Optional] Create a Dockerfile if it is necessary





## Rule for pom.xml
- For artifactId, keep using the SNAPSHOT so

## Rule for versioning 
- Tag format use v as prefix, such as v1.0.0 
- Update the CHANGELOG.md
